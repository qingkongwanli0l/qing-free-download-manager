# Qing Free Download Manager

Windows 桌面下载管理器。产品无需账号；需要网站授权的下载可使用用户提供的站点凭据。原创代码采用 MIT 许可证，独立运行的下载组件各自保留原许可证。

## 运行

需要 .NET Framework 4.8。目标兼容 Windows 7 SP1 及以上；Windows 7 的实际运行验证尚未完成。请按操作系统选择 x86 或 x64 程序。

运行 `QingFDM.exe`，通过“添加”输入链接、选择目录及队列。每行一个链接；连续编号可写为 `https://example.org/file[001-020].zip`。勾选立即加入运行队列后开始下载。媒体网页和播放列表使用“工具 → 媒体与播放列表”。本地媒体使用“工具 → 转换媒体”。

添加单个普通文件时，“读取文件信息”可显示服务器提供的名称、大小和类型，并保留已填写的文件名。读取只请求响应头，可以取消；服务器未提供的信息显示为未知。

添加窗口可勾选将目录保存到所选分类或文件类型。后续同类型文件优先使用保存的类型目录，本次手工选择的目录优先；取消窗口不会保存这些偏好。

分类按扩展名匹配，`*` 表示全部类型。分类中填写网站时，文件还须来自对应域名或子域名；仅填写网站则匹配该站点的所有类型。手工选择分类不受自动匹配规则限制。

“文件 → 批量下载”可勾选需要的链接、编辑文件名、按名称或链接文字筛选，并统一设置目录和队列。每行也可写 `URL || 文件名`。可选的响应头扫描读取类型、大小和文件名；筛选不会取消隐藏项的勾选。

暂停保留已下载内容。普通 HTTP 文件恢复时校验最终下载地址的摘要以及服务器的资源标识或修改时间；地址或资源改变、无法核实或服务器不支持续传时从头下载，传输期间条件校验失败会报告错误。地址摘要随临时数据保存，不保存解析后的地址原文。普通移除可保留历史，永久删除文件使用单独的删除命令。队列支持日期、每日时间段及间隔执行；完成后电源操作提供 30 秒取消窗口。

普通 HTTP(S) 下载若在收到文件内容前遇到所附 Windows 下载组件不支持的 TLS 握手，会自动改用支持 TLS 1.3 的组件，并保留该任务的选择用于后续续传。服务器证书仍须通过验证。

HTTP 下载的失败重试设置仅用于 GET 请求。POST 失败后保留错误，由用户决定是否重新提交；收到 301、302 或 303 跳转时改用不带请求体的 GET，307、308 跳转则保留原方法和请求体。

HTTP(S) 的 curl 分支支持保持当前请求的暂停/继续，以及运行中调整单项限速。停止会结束请求并保留临时文件；POST 停止或程序退出后，再次开始会重新提交请求。单项限速与全局设置同时为正时，此分支使用较小值；跨 curl、aria2 和媒体下载的合计带宽控制仍未完成。

“使用服务器文件时间”开启时保留服务器提供的修改日期，关闭时使用下载日期；curl HTTP(S) 下载在 32 位程序中也可保留 2038 年之后的有效日期。

下载设置可开启“显示已解析的下载直链”，在任务详情和进度窗口查看普通文件本次传输实际使用的地址；添加窗口读取文件信息后会单独显示查询得到的地址。直链仅在内存中保留，不写入任务记录或备份；显示时隐藏地址中的用户名和密码。编辑任务和“复制原始链接”继续使用原始链接，未取得实际传输地址时也显示原始链接。

新配置提供文档、压缩包、程序、图片、音乐、视频、网页和其他八种默认分类。自动匹配时，自定义分类优先，默认分类随后，“其他”最后匹配；手工选择的分类和保存目录保持优先。在分类设置中可恢复所选默认分类的扩展名，或为已有配置添加缺少的默认分类；同名分类和已有规则不会被覆盖。分类目录为空时沿用当前下载目录。

“设置 → 提示”可分别恢复移除任务、删除文件、下载完成后关机倒计时和连续拒绝下载后的例外建议。移除确认中的“不再询问”仅在确认操作后保存；取消仍保留原设置。关闭关机倒计时后，已配置的完成后关机会直接执行。浏览器例外建议中的“不再建议”保存到桌面设置，之后可在提示页重新启用。

“队列 → 任务上移／任务下移”调整所选任务在各自队列中的顺序，支持多选；已有活动任务继续运行，后续任务按调整后的顺序开始。按列标题排序只改变列表显示。

在添加窗口或任务右键菜单选择“任务计划”，可为单项设置开始、停止、每周或间隔循环；间隔从上一轮完成时起算。计划受所属队列和并发数限制，手动暂停后需要继续任务。“文件已存在时编号保存”用于保留同一链接的多次产物。

浏览器扩展在 `browser/chromium` 和 `browser/firefox`。通过“工具 → 浏览器集成”查看安装步骤并注册本机通信。浏览器自动接管及凭据传递需在扩展中主动开启。若扩展提示缺少网站访问权限，点击“允许网站访问”并在浏览器中确认，然后刷新已打开的网页。Firefox 正式安装需要签名扩展；未签名目录只能临时加载。

若交接后连接中断，扩展会保留浏览器中的暂停任务并提示核对 Qing 的接收结果；核对后可在扩展中继续或取消该浏览器任务。明确未被 Qing 接收的任务按回交偏好处理。

链接失效时，选中未完成任务并使用“在浏览器中刷新地址”。打开原页面后重新选择下载链接，在刷新窗口核对并确认更新；已有任务的保存位置和设置会保留。未记录来源页面时需要填写页面地址。确认后会清理该任务的临时片段并从头下载，已经落成的文件保留；取消刷新后旧任务保持暂停。

种子任务可在“媒体与种子”页读取文件列表并勾选。磁链会先取得元数据。已下载文件可通过右键“校验文件摘要”计算 MD5、SHA1、SHA256、SHA512，并与粘贴的摘要比对。

选中已下载的媒体后，右键“拼接所选媒体”可按列表顺序合并片段。勾选“显示视频链接中的片段名”可用链接中的编号辅助调整顺序；此选项只改变列表显示。

视频与音频设置中的“下载后读取媒体文件信息”默认关闭。启用后，任务详情显示已保存的常见音视频文件的容器、时长、编码、分辨率、帧率和音轨信息；播放列表分别列出各文件。信息读取失败会在详情说明，不影响已保存的下载。

“在进度窗显示下载中视频画面”默认关闭，启用后从新开始的分片视频下载中提取已收到的画面，不另行请求媒体。此选项使用随程序提供的固定版本 yt-dlp 适配插件；不支持的格式、外部下载器或缺少初始化数据的续传可能没有画面。下载过程中关闭此项会隐藏画面，下次开始传输时停止启用解码。

“工具 → 第三方下载账号”可管理用户自己的 AllDebrid、Real-Debrid 和 Debrid-Link API 令牌，查询账号和站点状态并生成下载链接。第三方服务是否收费、支持哪些站点及链接有效期由其决定。

默认数据目录是 `%LOCALAPPDATA%\QingFDM`。在程序旁创建名为 `portable` 的空文件可改用程序旁的 `Data` 目录。站点密码、第三方账号令牌、代理地址、请求头与 POST 请求体使用当前 Windows 用户的 DPAPI 加密；这些信息不能直接迁移给另一台计算机或另一 Windows 用户。链接与本地路径保存在任务记录中；分享导出链接前请检查其中是否含访问令牌。

设置窗口的“应用”立即保存并保持窗口打开；之后点击“取消”仅丢弃尚未应用的修改。“恢复基本设置”先修改窗口草稿，保留保存路径、代理、账号、站点规则、分类和队列，应用后生效。

常规设置可选择系统、浅色或深色主题及字号。“查看 → 链接篮”打开可拖入链接的悬浮窗口，显示总速度、进度和完成数量。下载进度窗口可切换或固定任务，分别查看音视频轨进度和种子文件列表；是否自动显示、完成后关闭及关闭延迟可在下载设置中调整。

关闭常规设置中的“下载窗口居中”后，添加、批量添加和进度窗口会分别恢复上次关闭的位置。移除显示器后，窗口会回到可见的屏幕范围内。

“设置 → 声音”提供添加、完成、失败和全部完成四类提示，默认关闭声音。每类可单独启停，选择自己的 WAV 文件或留空使用 Windows 系统声音；试听可在未应用设置时播放。种子下载完成并进入做种时也会发出完成提示。

常规设置可分别启停下载开始和下载完成的系统通知；通知的显示时间遵循 Windows 的通知和辅助功能设置。

“传输时显示图标动画”让窗口与托盘图标在任务运行时显示箭头活动效果；关闭后保持静态图标。

“帮助 → 检查更新”查询本项目 GitHub Releases 中的稳定版本，显示更新说明并允许跳过版本。自动检查默认关闭，可在常规设置中启用、设置天数或恢复已跳过版本的提示。安装版仅在存在同架构安装包及 SHA256 摘要时提供“下载并安装”；校验成功后暂停任务并启动安装程序。便携版从发行版页面手动更新。

桌面设置可选择 English、简体中文、繁體中文、Deutsch、Français、Español 或 Português (Brasil)，重启后生效。首次运行可识别这些语言的系统区域设置；葡语区域统一使用巴西葡语。已有语言偏好与分类名称保持不变。安装程序仍可选择 English 或简体中文，首次运行沿用安装语言，已有语言偏好保持不变。浏览器扩展可分别选择安装；可选的种子和磁力链接登记把 Qing 加入 Windows 可选处理程序。默认程序仍由用户在 Windows 中选择。“工具 → 注册种子与磁链打开方式…”也可在安装后登记。

BT 设置可启用启动时检查 `.torrent` 默认程序；若当前默认程序不是此 Qing 安装，将提示打开 Windows 默认程序设置。提示可以关闭，并在 BT 设置中恢复。

“文件 → 导出设置与任务”可分别选择设置、当前任务和历史记录，生成 `.qingbackup` 文件。导入会替换所选范围，未完成任务保持暂停，下载文件不随备份复制。备份不包含代理地址、密码、API 令牌、请求头及 POST 请求体；迁移后需重新授权并核对路径。链接本身仍可能包含访问令牌，请妥善保管备份。

## 从源码构建

需要 Windows、PowerShell 5.1 或以上和 .NET Framework 4.8 Developer Pack。构建脚本从 NuGet 还原固定版本 Mono.Nat 3.0.4，并校验包摘要；包缓存位于系统临时目录的 `QingFDM-Build` 文件夹，可复用于离线构建。

```powershell
.\build.ps1 -Architecture x64 -OutputDirectory C:\Build\Qing-x64
.\build.ps1 -Architecture x86 -OutputDirectory C:\Build\Qing-x86
```

如果引用程序集不在标准位置，使用 `-ReferenceDirectory` 指定其 `v4.8` 目录。输出目录应放在源码目录外。

每个发行目录的 `engines` 子目录需要可在目标系统运行的以下独立程序。64 位 Windows 也可运行 x86 的独立工具：

| 文件 | 用途 | 上游 |
| --- | --- | --- |
| `aria2c.exe` | HTTP、HTTPS、FTP、BitTorrent | [aria2](https://github.com/aria2/aria2) |
| `curl.exe` | 文件信息查询、FTP/FTPS 请求 | [curl](https://curl.se/) |
| `qcurl.dll`、`libcurl.dll` | HTTP(S) 的 curl 分支：POST、带站点凭据及指定 curl 的任务 | 本项目的原生桥接与 [curl](https://curl.se/) |
| `yt-dlp.exe` | 网站媒体、HLS、DASH、播放列表 | [yt-dlp](https://github.com/yt-dlp/yt-dlp) |
| `ffmpeg.exe` | 合并、转换和媒体处理 | [FFmpeg](https://ffmpeg.org/) |
| `ffprobe.exe` | 媒体信息 | [FFmpeg](https://ffmpeg.org/) |
| `qjs.exe` | 媒体提取所需 JavaScript 运行时 | [QuickJS-NG](https://github.com/quickjs-ng/quickjs) |

可通过 `-EngineDirectory` 在构建时复制已经准备好的组件目录。上游最新版本不一定兼容 Windows 7；必须为目标系统选择合适构建，并保留对应版本的许可、依赖声明和所需对应源码。

`qcurl.dll` 和 `libcurl.dll` 必须与 `QingFDM.exe` 同架构，放在同一个 `engines` 目录，并提供 `curl-ca-bundle.crt`。原生桥接源码位于 `native`；准备好匹配架构的 curl 8.20.0 头文件、导入库和 MinGW MSVCRT 编译器后，可独立构建：

```powershell
.\native\build.ps1 -Architecture x64 -CompilerPath C:\Tools\w64devkit\bin\gcc.exe -CurlIncludeDirectory C:\Deps\curl\include -CurlImportLibrary C:\Deps\curl\x64\libcurl.dll.a -OutputDirectory C:\Build\Qing-x64\engines
```

libcurl 的依赖、构建配方和重链接材料随对应组件的源码包提供；其组合许可包含 LGPL 组件，不能以本项目 MIT 许可证替代。

单独打包浏览器扩展：

```powershell
.\browser\package.ps1 -Browser chromium -OutputDirectory C:\Build\Extensions
.\browser\package.ps1 -Browser firefox -OutputDirectory C:\Build\Extensions
```
